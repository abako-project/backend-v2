# Specifications

Create one directory per feature: `NNNN-kebab-case-title/`.

Required artifacts:

- `spec.md`
- `acceptance.feature`
- `design.md`
- `data-model.md`
- `threat-model.md`
- `tasks.md`
- `status.md`

Implementation is blocked until the status is `APPROVED` and all blocking questions are resolved.
