# leptos-web

The repository's example browser frontend, built with Leptos and WebAssembly.
It uses the adapter's public REST/SSE API for marketplace screens, operations and
notifications. It owns no authoritative business data or signing keys.

Start with [src/browser.rs](src/browser.rs). See [deployment](../../infra/README.md)
and [API documentation](../../crates/generated-contracts/API.md).
