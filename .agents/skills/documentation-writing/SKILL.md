# Documentation Writing

Read `docs/agentic/writing-standard.md` before editing prose.

1. Identify the reader and the decision or action they need.
2. Put the important fact first.
3. State each rule once.
4. Replace vague words with concrete paths, commands, actors, units, or conditions.
5. Mark assumptions and unknowns instead of guessing.
6. Remove filler after the technical content is complete.
7. Read the result once as a human reviewer.
