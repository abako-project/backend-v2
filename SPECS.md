# Specification Index

## States

`DRAFT -> SPEC_REVIEW -> APPROVED -> TASKED -> IMPLEMENTING -> VERIFYING -> REVIEWING -> READY_TO_INTEGRATE -> INTEGRATED -> RELEASED`

Additional states: `BLOCKED`, `SUPERSEDED`, and `CANCELLED`.

Only an authorized human owner or explicitly authorized reviewer may move a specification to `APPROVED`.
