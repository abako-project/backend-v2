# generated-contracts

Shared Rust types for REST requests/responses, signed provider commands, receipts,
events and compact core views. Includes wire validation and JSON/SCALE encoding.
Despite the name, this is maintained Rust source, not the ink smart contracts.

Start with [src/lib.rs](src/lib.rs). See the [API guide](API.md) and
[OpenAPI contract](../../contracts/openapi.json).
