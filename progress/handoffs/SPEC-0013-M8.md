## Changes

The SDK worker supports explicit whole-provider `rust`, `shadow` and `sandbox`
modes. Rust executes native logic; shadow observes WASM beside native authority;
sandbox observes native logic beside WASM authority. The existing default app
remains SDK-free. Authority enters checkpoint configuration identity. Switching
modes requires current-state export and fresh import.

The existing bounded worker and SQLite transaction own both engines. A new
`candidate_reference` row retains native state and comparison status. One verified
call and captured input set feed tentative evaluation. Primary infrastructure
failure commits nothing. Domain failure commits its failed receipt and nonce.
Replays do not advance revision. Reference failure marks comparison incomplete;
differences remain explicit. Derivative execution stops after either condition,
while the selected primary continues. There is no fallback or re-execution.

The existing HTTP handlers use `ProviderApi`; whole-provider queries run existing
native read models over the selected primary archive on the worker. Legacy
fixture projections reject whole-provider access. The isolated `whole-provider`
binary offers serving and offline import/export/diagnostics. The isolated native reference uses the existing `mock-seed` feature; whole-mode
startup rejects funding-disabled configuration rather than comparing different
policies. Existing fixture APIs keep their disabled-funding coverage. Legacy databases and
incompatible authorities are rejected; import/export never overwrite a file.
Complete current state, rather than an old cutover snapshot, is the rollback input.

Native retained workers with 512 skills exposed excessive index host work. The
canonical helper now stores bounded primitive indexes in single cells; Directory
updates only added/removed memberships. Contract selectors, argument/result
shapes and behavior remain unchanged. Kreivo storage, memory and code caps remain
unchanged. The separate whole-provider allowance is finite at 2e12 ref_time and
128 MiB proof size; explicit earlier fixtures retain their original allowance.
Whole-mode metering/trap/language failures abort before shell completion.
