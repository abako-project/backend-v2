## E1: native and adapter

Four appended commands reuse existing handlers, permissions, transitions, money
rules and failed-operation semantics. Evidence slots hold Legacy or Committed;
there is no separate provider evidence catalog. Old signed-command encodings,
legacy JSON and native SCALE bytes remain unchanged. New storage references
have an explicit bounded version discriminator.

The adapter retains complete evidence and signs a context-bound SHA-256/SCALE
commitment. Frozen vectors bind generation, project, purpose, target, ID, author,
kind and exact bytes, including opaque legacy URL digest fields. Existing text
stays in existing scoped tables. New URL records and pending operations share
one transaction after queue admission. Original request bytes preserve queue
retries; existing HTTP target/current-state checks are not broadened. Operations
retain their evidence generation and reject a reset before signing.

Public projections verify and hydrate only visible projects or the requested
case. They preserve frontend response shapes and reuse verified text. Missing or
tampered records fail explicitly; raw authorization, private channels, unrelated
projects and later arguments do not require their preimages. Old comment-only
history stays unanchored. Delivery presentations, later arguments and private
messages gain no transactions. The additive migration is applied idempotently
under the existing startup lock.

## E2: canonical and SDK

Canonical runtime source is `139a01fe49d850d7a0188418c40e4714c8ceb9e6`;
`ed67b62` only corrects documentation. Project stores
`LegacyReferenceHash(hash)` or `Committed(record_id, hash)`. Four new commands
use existing Project selectors and domain handlers. References source, wiring,
artifact and build lock are removed. Three contracts execute current business
logic; four older test fixtures remain. Broader fixture packaging is separate.

Explicit private wire DTOs convert the changed contract SCALE layout. A bounded
SDK checkpoint map retains at most 16,384 exact legacy references within the
existing 64 MiB state budget. Legacy hashes use the specified separate domain;
new commitments pass through unchanged. Business rejection discards tentative
preimages; infrastructure failure commits neither runtime nor shell/map changes.
Missing or mismatched entries fail explicitly. Complete import/export, restart
and native rollback preserve old URLs, digests, unanchored comment IDs and new
commitments without reading PostgreSQL.
